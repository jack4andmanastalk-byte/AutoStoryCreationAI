## 要約

本報告は、「日本における物語の創作技法」を、日本固有の不変な形式ではなく、**戦後の日本の娯楽・映像文化で実践・分析・紹介・提案された、物語を作り、伝え、検討するための操作**として扱う。原産地が海外であっても、日本語の出版、国内の研究や実務講演などによる受容が確認できるものを含めた。

116項目は、企画・発想8、構造・展開12、人物・関係12、情報・伏線10、語り・時間10、場面・台詞8、漫画の画面・読順10、映画的な撮影・編集・音12、アニメーション固有の構成10、ゲームの相互作用・参照系10、異世界・ゲーム的世界の設計4、制作工程・改稿・翻案10に整理した。これは技法の自然な総数や重要度順位を示すものではなく、文献と操作単位を対応付けるための編集上の分類である。

主要な知見は次の五点に要約できる。

1. **筋立てだけを扱うと、創作技法の重要な部分が抜ける。** 出来事そのものの組立てと、提示順・情報アクセス、画面や音による表現、改稿・共同制作の工程を分ける必要がある。本報告の概念整理は、物語内容・言説・表現を区別する小方の議論を参照するが、116項目への再分類は本報告の編集判断である。[S022](#s022), pp.208–210。
2. **国内の実務的助言と海外理論の日本語での受容が併存する。** 例えば三幕構成・ビートシートの日本語紹介と、漫画編集者や脚本家が語る人物・連載設計は、出自と根拠の種類が異なる。これらを「日本では誰もが使う一つの型」に統合することはできない。[S030](#s030)–[S034](#s034)、[S064](#s064)、[S083](#s083)。
3. **互いに異なる方法も選択肢として残す必要がある。** 人物の変化には成長型だけでなくフラット型・転落型が紹介され、人物の準備についても詳細な設定を勧める助言と、最小限から会話を作る作家の実践がある。これらは誤差ではなく、方法の複数性として記録した。[S078](#s078)、[S041](#s041)、[S087](#s087)。
4. **媒体の条件は技法の働き方を変える。** 漫画の読順や見開き、アニメーションの止め・反復・画面外の処理、ゲームの変数や周回条件は、単に同じプロットの見た目を変えるだけではない。何がいつ分かり、何を経験できるかを変える操作として扱った。[S036](#s036)、[S009](#s009)、[S052](#s052)–[S054](#s054)、[S015](#s015)。
5. **効果を測った研究は、条件を伴って読む必要がある。** 例えば線による注意喚起やショットの時間的連続性の実験は、限定された刺激・課題での知見である。販売成績、物語の面白さ、芸術的評価の普遍的向上をそのまま導くことはできない。[S008](#s008)、[S057](#s057)。

|論点|本報告の扱い|

|「日本における」|国内の制作者・編集者・開発者の証言、国内作品の分析、国内の研究者による提案、日本語出版・国内講演を通じた海外理論の受容を区別して採用する。|
|古い／海外の作品|戦前の海外映画などは、戦後の国内文献での理論的受容としてのみ扱う場合がある。戦後日本の制作実践の直接証拠とはしない。|

|対象外|古典芸能・口承文芸の包括的整理、1945年以前の技法史、創作者人口・採用率の推定、全商業作品の悉皆分析。|

### 1.2 収集と選別

J-STAGE、大学・研究機関リポジトリ、出版社と編集部の公開資料、公式開発者インタビュー、CEDECの公開講演概要、実務講演の報道、ツール開発元のチュートリアルをウェブ検索と関連資料の追跡で収集した。**検索結果の総件数やデータベースの全件スクリーニングを記録した系統的レビューではない。** 非公開の講演資料・動画、有料書籍の本文、閉鎖された記事は確認したことにしない。

検索語群には、物語生成・物語構造・創作支援、漫画のコマ割り・ネーム・編集、アニメーションの演出・作画、シナリオとCEDEC、脚本家インタビュー、ライトノベル編集、三幕構成等を用いた。完全な検索式・検索順位・各検索時刻の履歴は保存していないため、同じ検索結果集合を厳密に再現することはできない。代わりに、**候補URLごとの収集・採否記録と、採用資料の確認範囲・頁／節を残した。**

- 候補としてIDを付した記録：**87件**。これは検索エンジンが返した全件数ではない。
- 採用文書：**59件**。うち**58件**が技法の根拠に直接対応し、S022は概念整理に用いた。
- 別途書誌を確認した同一文書の記録：S080→S015、S081→S055として統合。独立した二文献とは数えない。
- 採用資料の内訳：学術系**25件**、実務・出版・報道系**34件**。学会予稿・技術報告・研究ノートも学術系に含めるが、査読の有無を一律に仮定しない。
- 本文全体または関連本文の抜粋を確認したもの：**53件**。要旨・公式概要に根拠を限定したもの：**6件**（S004・S005・S045・S046・S047・S049）。前者53件を「53文書すべて全文精読」と解してはならない。
- 収集時にメンテナンス、無関係な転送、文字抽出の問題、記事本文未取得等があったものは、その状態を記録して不採用とした。HTTP200も本文を確認できた保証にはしなかった。

採用の基本条件は、①範囲との関係が説明できる、②操作・記述枠組みが確認できる、③出典と根拠箇所をたどれる、④証拠の範囲を超えない形で項目化できる、の四つである。要旨・概要のみの場合は、そこに明記された枠組みや機能に限定した。全文や講演詳細の存在を仮定して項目を補完していない。

### 1.3 項目化・重複・数え方

各項目にはT001〜T116、資料には収集時のS番号を付けた。S番号の欠番は選別の跡である。名称は索引しやすいように編集したもので、常に原典の術語そのものではない。**「操作」は原文の逐語引用ではなく、本報告が資料から作業手順へ変換した要約・総合である。**

三幕の各部分、15のビート、ショット距離の各種類を、それぞれすべて別の技法に数えることは避けた。一方で、同じ伏線でも接続関係が違うもの、同じ止め絵でも背景・画面外・撮影上の処理が違うものは、操作が区別できる範囲で分けた。この粒度には編集判断が入っている。分類を別の理論で組み替えれば項目数も変わる。

媒体ごとの独立した100件ずつの一覧ではなく、共通の操作はまとめ、媒体条件による差は文脈と留意点に記した。後続研究で頻度を数える場合には、この分類を自然な母集団や、互いに独立した説明変数とみなさず、別途コーディング規則を定める必要がある。

### 1.4 根拠の区分と記号の読み方

|関係タグ|意味|それだけでは意味しないこと|
|---|---|---|
|実践|国内の制作者等の経験・証言、国内出版社の実務的助言、開発元等の実務資料。|実作品の独立検証、広い採用率、効果の因果実証。|
|分析|作品や形式を対象とする記述・解釈からの操作化。|作者が意図した手順の直接証言。|
|受容|海外理論等の国内出版・研究・講演での紹介や検討。|日本の全業界での実践、理論の普遍的妥当性。|
|提案|国内研究者等の記述・生成・創作支援のモデル。|既に標準化・商用化・一般実証されていること。|
|実験|特定の刺激・参加者・評価課題による検討。|異なる媒体・観客・長編作品への効果の保証。|
|実装指南|ツール開発元の文書で具体的な作り方を確認。|分岐数や機能数が物語品質と比例すること。|

複数タグは複数の関係を示すだけで、証拠を足して強さの点数にしたものではない。カタログの「確認文脈」は資料で確認できた領域を示し、他媒体への転用が不可能という意味でも、既に有効性が確認済みという意味でもない。

「狙い」はその操作が担いうる機能の整理であり、各資料が統計的に証明した従属変数とは限らない。研究論文・制作証言・規範的助言・宣伝的紹介・二次報道を同じ証拠として扱わないため、資料種別と確認範囲を文献欄・JSONLに保存した。特に、フィルムアート社の10本の記事は、複数の独立した学派の調査でも、10冊の書籍を通読した記録でもない。

## 2. 概念整理：何を「創作技法」として記録するか

本報告では、次の四層を相互に関係するものとして区別する。これは、小方の物語内容・言説・表現の議論（[S022](#s022), pp.208–210）を参照した**本報告の操作的整理**である。

1. **出来事・世界・人物の層**：誰が何を望み、どの規則の下で何が起きるか。企画、因果、人物関係、世界の制度など。
2. **語り・情報の層**：どの順番で、誰の知識の範囲から、何を明かし／伏せるか。伏線、回想、視点、再提示など。
3. **媒体表現・相互作用の層**：読順、画面の時間、隣接ショット、音、選択肢や到達記録をどう構成するか。
4. **制作・検討の層**：案を記録する、カードで並べる、声に出して点検する、担当者間で整合させる、翻案し直すなど。

絵を上手に描く技術一般や、プログラムを書く技術一般を無制限に含めてはいない。線・余白・変数などは、注意、出来事の理解、人物の心理、提示の順序・条件に関与する範囲で採用した。また「悲しさ」「異世界」「成長」などは、それだけでは技法ではない。何を選び、どの関係を変え、どの条件を設定するかまで操作として書ける場合に項目化した。

個々の項目は、①確認文脈と日本との関係、②操作、③狙い、④留意点、⑤資料IDと頁／節、の順に読む。「基本」や「正しい物語」のチェックリストではなく、**特定の創作上・分析上の問いに使える選択肢の索引**として利用されたい。

## 4. 技法カタログ（116項目）


### A. 企画・発想

<a id="t001"></a>

#### T001 着想の外部記録（ネタ帳）

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：日常で気になった事実、感情、台詞、構図を短く記録し、企画時に検索・組合せの材料として取り出す。完成した筋だけを保存対象にしない。
- **狙い**：瞬間的な発想の散逸を防ぐ。
- **留意点**：記録量と作品の質の因果関係は未検証。実在人物の私生活や他作品の表現を、そのまま流用しない。
- **根拠**：[S067](#s067)（「タネ帳」、描きたいもののタネを日頃からメモする説明）。

<a id="t002"></a>

#### T002 好みの要素の複合

- **確認文脈／日本との関係**：漫画・ライトノベル／実践。
- **操作**：好きな作品の人物、目的、舞台、デザインなどを要素別に抽出し、複数の異なる要素を組み合わせ直す。外形だけでなく、その要素に惹かれた理由を考える。
- **狙い**：独自性のある企画の出発点を作る。
- **留意点**：複合は盗用の免罪符ではない。藤本の証言は主にデザイン、電撃編集部の助言は小説の企画に関する。
- **根拠**：[S041](#s041)（「自分の“好き”をミックス！」）；[S087](#s087)（「悪魔や魔人のデザインはどのようにして思いつくんですか？」への回答）。

<a id="t003"></a>

#### T003 定型＋理由のあるギャップ

- **確認文脈／日本との関係**：ライトノベル／実践。
- **操作**：読者が知っている類型を一つ選び、そこから予想される属性と逆向きの属性を与える。なぜその差異が生まれたのかを経歴や価値観に結び付ける。
- **狙い**：理解の足場を残して意外性を作る。
- **留意点**：奇抜さだけでは奥行きにならない。類型を知らない読者にも意味が通るかを確認する。
- **根拠**：[S041](#s041)（「『定型』と『ギャップ』のバランス」「みんなが知ってる当たり前に逆張り」）。

<a id="t004"></a>

#### T004 時代・発表場所・自分の強みの照合（T・P・O）

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：時代の傾向（TIME）、掲載・発表する場所（PLACE）、自分の描けること（OWN）を別々に書き出し、企画が三者にどう適合し、何で差別化するかを点検する。
- **狙い**：企画と制作条件の不一致を見つける。
- **留意点**：この講義のOはOWNであり、一般的なoccasionではない。市場適合だけを作品価値の基準にしない。
- **根拠**：[S065](#s065)（「TIME」「PLACE」「OWN」の各説明）。

<a id="t005"></a>

#### T005 調査から架空の制度を設計する

- **確認文脈／日本との関係**：テレビドラマ／実践。
- **操作**：実在制度の機能・制約・未実現案を調べ、物語に必要な活動を担える架空の組織を設計する。事実に基づく部分と創作した部分を分け、専門家に整合性を相談する。
- **狙い**：取材の具体性とドラマ上の自由を両立する。
- **留意点**：『アンナチュラル』の研究所設計に関する個別証言。実在の職域を誤って説明することとは区別する。
- **根拠**：[S083](#s083)（「不自然死究明研究所」の舞台設定とリアリティラインへの回答）。

<a id="t006"></a>

#### T006 テーマを行為の帰結で検討する

- **確認文脈／日本との関係**：日本語創作指南（小説・脚本理論）／受容。
- **操作**：抽象的な主題を、人物が選択した行為とその結果の関係へ置き換える。結末が主題を単に口で述べるのではなく、支持・反証・複雑化しているかを確認する。
- **狙い**：主題と出来事の分離を防ぐ。
- **留意点**：ワイランドの理論を紹介する日本語記事による。すべての物語に単一の教訓や命題を要求するものではない。
- **根拠**：[S035](#s035)（「要点その③：テーマをプロットで立証する」）。

<a id="t007"></a>

#### T007 事件の背後の社会構造へ焦点を移す

- **確認文脈／日本との関係**：テレビドラマ・映画／実践。
- **操作**：題材となる事件の個人だけでなく、制度、貧困、権力関係などの条件を調べる。複数の立場へ取材し、実事件を加工する場合は当事者を特定させる情報と影響を点検する。
- **狙い**：社会的題材を人物攻撃に還元しない。
- **留意点**：野木の制作姿勢の整理であり、特定の政治的解釈の正しさを保証しない。取材同意・名誉・プライバシーの検討が別途必要。
- **根拠**：[S084](#s084)（単独インタビュー「『社会派』と呼ばれるが」）。

<a id="t008"></a>

#### T008 人物×状況による連載エンジン

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：人物の行動原理を定め、その人物に別の相手、危機、誘惑、依頼をぶつける。毎回新しい設定を増やす前に、既存人物がその状況へどう反応するかから一話を組む。
- **狙い**：継続的にエピソードを生成する。
- **留意点**：浅田による週刊連載上の経験則。状況の交換だけで人物が停滞する場合は、関係や結果も更新する。

### E. 語り・時間

#### T043 人称と情報アクセスの分離

- **確認文脈／日本との関係**：日本語創作指南（小説）／受容。
- **操作**：「私／彼」のどちらで語るかと、誰の感覚・記憶・内面へ接近できるかを別々に決める。同じ三人称でも知り得る範囲は違うものとして設定する。
- **狙い**：表現形式と知識範囲の混同を避ける。

<a id="t044"></a>

#### T044 外面観察に限定する語り

- **確認文脈／日本との関係**：日本語創作指南（小説）／受容。
- **操作**：発言、動作、見える環境を主に記し、人物の考えを直接には断定しない。読者が表情や行動から内面を推測できるよう、選ぶ細部を調整する。
- **狙い**：内面の推測や距離感を作る。
- **留意点**：記事の「客観視点」の操作化。観察対象の選択には語りの偏りがあり、価値中立を保証しない。
- **根拠**：[S076](#s076)（「客観視点」に関する説明）。

<a id="t045"></a>

#### T045 単一人物への限定視点

- **確認文脈／日本との関係**：日本語創作指南（小説）／受容。
- **操作**：一つの区間で接近する人物を定め、その人物が知らない事実や他人の内心を無標識で述べない。推測と知覚した事実を区別する。
- **狙い**：同伴感と情報制限を作る。
- **留意点**：視点の切替自体は禁止ではない。切替の境界と、読者がそれを理解できる手掛かりを設ける。
- **根拠**：[S076](#s076)（「限定視点」と視点人物が知りうる情報の説明）。

#### T046 全知的な情報配置

- **確認文脈／日本との関係**：日本語創作指南（小説）／受容。
- **操作**：複数人物の内面、遠隔地、過去や未来などへ接近する語りの権限を設定する。どの場面でどこまで伝えるかを選び、情報を知っていても常時すべて述べない。
- **狙い**：比較・俯瞰・劇的な情報差を利用する。
- **留意点**：全知は無秩序な視点移動の同義語ではない。記事の分類を、日本語小説全体の実態調査と扱わない。
- **根拠**：[S076](#s076)（「全知視点」の説明）。

#### T047 信頼できない語り手

- **確認文脈／日本との関係**：日本語創作指南（小説）／受容。
- **操作**：語り手の認識、記憶、評価と、別の証拠が示す事実の間にずれを作る。そのずれを読者が後から検討できる手掛かりを残す。

- **留意点**：誤記や無根拠などんでん返しとは区別する。資料は日本語での理論紹介で、特定の日本作品の実践確認ではない。

- **留意点**：S056のfrequency概念の操作化であり、同一の映像を無意味に繰り返すことではない。日本作品での実践例の網羅はしていない。

- **留意点**：役割語は虚構上のステレオタイプで、実際の性別・年齢・地域集団の自然な話し方を証明しない。偏見の再生産に注意する。

- **狙い**：単調な情動を避け、人物の生の厚みを示す。
- **留意点**：悲劇の被害や当事者を笑いの対象にすることとは異なる。野木の作風上の判断を全ジャンルの原則にしない。

#### T060 会話を説明の都合へ無理に従わせない

- **確認文脈／日本との関係**：漫画・ライトノベル／実践。
- **操作**：情報を渡す必要と、その場で人物が話す理由を分けて考える。人物の目的や関係から不自然になる説明は、別場面・別表現へ移すか省く。
- **狙い**：会話が作者の解説に見えるのを避ける。
- **留意点**：藤本の回答は短い制作方針で、細かな会話理論までは示していない。本項の点検手順は報告側の操作化。
- **根拠**：[S087](#s087)（「会話がすごくリアル…」への回答）；[S041](#s041)（編集者N「キャラの人生の物語」を書こう）。


### G. 漫画の画面・読順

<a id="t061"></a>

#### T061 読順とコマ間隔の設計

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：右開きの読順を前提に、右から左、上から下へ迷わず進める配置を作る。次に読ませたいコマとの間隔と段間を調節し、複数の読み方が競合する箇所を見直す。
- **狙い**：読む順番の迷いを減らす。
- **留意点**：S072の寸法やコマ数の目安は紙面用の実務助言。左開き、縦スクロール、小画面へそのまま一般化しない。
- **根拠**：[S072](#s072)（「ルールその1」「ルールその2」）。

<a id="t062"></a>

#### T062 吹出しを起点にした視線誘導

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：台詞の順序を先に確認し、吹出しの間に見せたい顔や動作が入るよう配置する。吹出しの尾で発話者が曖昧にならないかも点検する。
- **狙い**：台詞と重要な絵を一つの読路へ結ぶ。
- **留意点**：視線を「必ず」誘導できるという実験結果ではない。読みやすさのための齊藤の編集上の助言として扱う。
- **根拠**：[S036](#s036)（吹出し、重要な顔、尾の向きに関する説明）。

<a id="t063"></a>

#### T063 顔と手の芝居による感情提示

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：台詞や顔の表情だけでなく、手の位置、握り方、身振りを描き、人物が何を感じ何をしようとしているかを見せる。必要な情報が読めるショットの大きさも選ぶ。
- **狙い**：言葉と表情の説明負荷を分散する。
- **留意点**：身振りの意味は文脈や文化で変わる。特定の手の形に普遍的な心理状態を割り当てない。
- **根拠**：[S036](#s036)（手を描くこと、距離・人物配置による伝達の説明）。

<a id="t064"></a>

#### T064 コマの大小の対比

- **確認文脈／日本との関係**：漫画／実践＋分析。
- **操作**：重要な情報や感情を担うコマと、その前後のつなぎのコマの面積差を作る。大コマの絶対サイズだけでなく、隣接する小コマとの対比で強調を調整する。
- **狙い**：注意の重みと読みの緩急を作る。
- **留意点**：S077は購買数上位74作品の第1話を対象とする分析で、最適コマ数の実験ではない。数字を全漫画の規則にしない。
- **根拠**：[S037](#s037)（大きい・小さいコマの限界とメリハリの説明）；[S072](#s072)（「ルールその3」）；[S077](#s077)（pp.57–59、コマ数と強調の考察）。

<a id="t065"></a>

#### T065 見開き単位での配置確認

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：一ページずつではなく左右二ページを並べ、目立つコマの位置、密度、情報の競合を見直す。片ページで窮屈でも見開き全体では機能する場合を区別する。
- **狙い**：実際の読書面で強弱と構図を確認する。
- **留意点**：見開きのない端末表示では別の検証が必要。紙とスマートフォンの見え方の差はS037も問題にしている。
- **根拠**：[S072](#s072)（「ルールその4」）；[S037](#s037)（紙とスマホでのコマ・見開きの見え方への言及）。

<a id="t066"></a>

#### T066 物や身体の向きによるコマ内の導線

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：ボール、身体、視線などの向きが、次に見てほしい位置へ視線を運ぶかを確認する。文字の流れと絵の方向が衝突する場合は配置を変える。
- **狙い**：絵の構図を読路の手掛かりにする。
- **留意点**：古舘の具体的なコマ設計の証言。物体の向きだけで全読者の視線が決まるという一般法則にはしない。
- **根拠**：[S037](#s037)（ボール等の向きと読者の視線の動きに関する説明）。

<a id="t067"></a>

#### T067 隠してから明かす画面構成

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：初めのコマでは人物・物・状況の一部だけを見せ、後続のコマで全体や決定的な部分を開示する。開示前の推測が後でどう更新されるかを設計する。
- **狙い**：コマをまたぐ発見や驚きを作る。
- **留意点**：伏線の長期的な張り回収とは異なり、局所的な可視範囲の制御を操作対象とする。曖昧さが必要情報の欠落にならないか確認する。
- **根拠**：[S037](#s037)（何を見せ、何を隠すか、コマの配置と開示に関する説明）。

<a id="t068"></a>

#### T068 密度に合わせた背景・遠近の整理

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：縦に細かく割ったコマや吹出しの多い場面で、背景・遠近・人物配置が読みを妨げていないか点検する。必要な空間情報を残しつつ、描込みや配置を整理する。
- **狙い**：情報密度と空間理解の釣合いを取る。
- **留意点**：筒井と編集者の修正経験に基づく。背景を省けば常に良くなる、あるいは正確な遠近法が不要という意味ではない。
- **根拠**：[S038](#s038)（縦方向のコマ、吹出しと遠近感、編集者の指摘への回答）。

<a id="t069"></a>

#### T069 集中線による注目点の設定

- **確認文脈／日本との関係**：漫画／実践。
- **操作**：強調したい人物や物に中心点を定め、周囲から放射状の線を配置する。線の密度、長さ、中心との距離を調整し、対象が埋もれないようにする。
- **狙い**：注意と強調の中心を画面に作る。
- **留意点**：S073は作画の実務講座。特定の心理・感情や視線効果の普遍性を実証した資料ではない。
- **根拠**：[S073](#s073)（「1）読み手の視線を集める『集中線』」）。

<a id="t070"></a>

#### T070 スピード線による運動方向の提示

- **確認文脈／日本との関係**：漫画／実践＋実験。
- **操作**：物体の移動方向や勢いに合わせて線の方向、長さ、粗密を調節する。背景の流れと物体の動きが混同されないか、線を除いた絵とも比較する。
- **狙い**：静止画に運動の手掛かりを付与する。
- **留意点**：S008の効果は限定した図形・注意課題の条件に依存する。すべての線配置で運動方向への注意が促進されたわけではなく、作品の面白さも測っていない。
- **根拠**：[S073](#s073)（「2）絵に迫力を出す『スピード線』」）；[S008](#s008)（pp.81,85–86、参加者・結果・考察）。


### H. 映画的な撮影・編集・音

<a id="t071"></a>

#### T071 ショット距離と画面に入れる情報の選択

- **確認文脈／日本との関係**：映画／受容＋分析。
- **操作**：全身や場所を示す画と、顔・手・物を大きく示す画を、伝えたい情報に応じて選ぶ。表情の強調と空間関係の説明を同時には満たせない場合、その順序を決める。
- **狙い**：情報の広がりと細部への集中を調整する。
- **留意点**：距離ごとの名称を別々の技法に数えない。近景が必ず親近感を生む等の因果主張は、本報告では採用しない。
- **根拠**：[S055](#s055)（pp.26–28、フレーム・サイズ・アングルの説明）。

<a id="t072"></a>

#### T072 長回しと画面内の配置

- **確認文脈／日本との関係**：映画／受容＋分析。
- **操作**：カットを増やす前に、人物の位置や動き、カメラ位置によって一つのショット内で場面の変化を見せられないか検討する。見せたい行為が隠れない導線を作る。
- **狙い**：切替に頼らず行為や関係の連続を示す。
- **留意点**：長いショットが必ず落着き、短いショットが必ず興奮を生むとは扱わない。撮影・演技・安全上の条件も必要。
- **根拠**：[S055](#s055)（p.26、カット割りとカメラポジション、長回しの説明）。

<a id="t073"></a>

#### T073 カメラ移動による追跡・開示

- **確認文脈／日本との関係**：映画／受容＋分析。
- **操作**：被写体を追う、人物へ接近する、周囲を見せるなど、移動の目的を先に定める。固定、パン、移動撮影、ズームの違いを、画面内の情報変化として比較する。
- **狙い**：時間とともに見る範囲や距離を変える。
- **留意点**：S055には効果を断定的に述べる箇所もあるが、本報告は撮影選択肢の整理として使う。機材や運用ごとに安全・許可の検討が必要。
- **根拠**：[S055](#s055)（pp.28–29、移動撮影・パン等の説明）。

<a id="t074"></a>

#### T074 隣接ショットによる意味の再構成

- **確認文脈／日本との関係**：日本語映画論／受容。
- **操作**：同じ顔や物のショットに、別の対象や状況のショットを接続し、前後関係で生じる解釈を比較する。単独画面の意味と、並置で生まれる意味を分けて検討する。
- **狙い**：画面の結合によって含意を作る。
- **留意点**：S055のクレショフやプドフキンの紹介による。原実験を本調査で再確認したわけではなく、国内作品での効果の実証でもない。
- **根拠**：[S055](#s055)（p.32、『母』とクレショフ効果を紹介する部分）。

<a id="t075"></a>

#### T075 長さと動きの拍による編集リズム

- **確認文脈／日本との関係**：映像編集研究／受容＋提案＋実験。
- **操作**：ショットを一定の長さで並べる案と、画面内の動作の拍やアクセントに合わせる案を作り、リズムの差を比較する。作品の意味内容とは別に切替の形式も点検する。
- **狙い**：視覚的なリズムを構成する。
- **留意点**：S058は海外映画素材を再編集する研究である。16種類を16技法に数えず、条件ごとの効果を万能な編集規則にしない。
- **根拠**：[S058](#s058)（pp.447,450、メトリック／リズミック・モンタージュと実装方法）。

<a id="t076"></a>

#### T076 連続性を切る編集

- **確認文脈／日本との関係**：映像編集研究／受容＋提案＋実験。
- **操作**：時系列や人物の連続を意図的に断ち、出来事の筋以外の画面、音、切替それ自体へ注意が向く配列を試す。連続を回復する版と比較する。
- **狙い**：物語への没入とは異なる知覚を働かせる。
- **留意点**：S058は切断による視点移行を論じるが、切断が常に優れた効果を生むとはしない。単純な編集ミスと意図的な切断を区別する。
- **根拠**：[S058](#s058)（pp.448–450、切断的側面、時間軸・人物の切断の説明）。

<a id="t077"></a>

#### T077 動作をまたぐカットの調整

- **確認文脈／日本との関係**：映像知覚実験・映画編集論／受容＋実験。
- **操作**：同じ動作を複数の画角でつなぎ、直結、短い省略、短い重複を比較する。動作のどこで切るかと、前後の画角・注視点を一緒に調節する。
- **狙い**：切替前後の動作の連続感を整える。
- **留意点**：S057は32名、単純な短い映像を用いた実験。最適な開始位置は出来事・画角に依存し、一定ミリ秒の省略や重複を万能解にできない。
- **根拠**：[S057](#s057)（p.651、実験方法;pp.656–657、考察・まとめ）。

<a id="t078"></a>

#### T078 画面外の声を人物への圧力にする

- **確認文脈／日本との関係**：映画／分析。
- **操作**：話し手の画から聞き手の画へ移った後も声を残し、聞き手の領域へ言葉が入り込む状態を作る。表情の反応とは別に、声の持続と関係性で圧力を表す案を考える。
- **狙い**：声と画面の支配関係を表現する。
- **留意点**：S059の小津『お茶漬の味』に関する解釈の操作化であり、監督の明示した一般的制作手順ではない。通常の反応ショットとは区別する。
- **根拠**：[S059](#s059)（pp.38–42、カッティングポイントの前倒しと画面外の声の圧力）。

<a id="t079"></a>

#### T079 音楽と映像の意味的な対比（音と画の対位法）

- **確認文脈／日本との関係**：映画／分析＋実験。
- **操作**：場面の印象と一致しない音楽を意図的に置き、両者の対比がどう読まれるか検討する。劇世界の中に音源があるかなど、組合せの理由も設計する。
- **狙い**：単純な感情強調とは異なる複雑な印象を作る。
- **留意点**：S061は黒澤『野良犬』の一部を用いた検討。音源の見え方にも効果が依存し、不一致音楽が常に高評価になるとはいえない。音楽理論の対位法とは別義。
- **根拠**：[S061](#s061)（pp.387,395、要旨・結論と音源を隠す操作の議論）。

<a id="t080"></a>

#### T080 台詞後の音楽開始時点の調整

- **操作**：台詞の終わりを基準に音楽の入りを前後へずらした版を作り、間の感じ方と台詞の印象を比較する。曲の印象だけでなく、台詞が表す感情も条件として記録する。
- **狙い**：台詞の余韻と音楽の作用を調節する。
- **留意点**：S060では8映像刺激・3種の感情等の条件を検討。すべての台詞に共通する最適秒数は示されていない。
- **根拠**：[S060](#s060)（pp.51–52、刺激・方法;p.58、結論）。

<a id="t081"></a>

#### T081 音と映像の微小な時間差の調整

- **確認文脈／日本との関係**：日本語アニメーション・映画音響論／受容＋分析。
- **操作**：画の変化と音の発生を編集上の同一時点に置く版だけでなく、画をわずかに先行させる版などを比較する。動作の速さと衝撃の種類に応じて知覚上のまとまりを確認する。
- **狙い**：物理的同時と知覚上の同時の差を扱う。
- **留意点**：S062の動画先行論は主にディズニーと海外映画を扱う。日本語での検討の根拠であり、全作品に固定フレーム数を適用する規則ではない。
- **根拠**：[S062](#s062)（pp.61,65,69、簡易調査、ショック・シーンへの適用とフレーム処理の議論）。

<a id="t082"></a>

#### T082 シーン構成表とプレビズによる演出共有

- **狙い**：専門分野をまたぐ物語演出の足並みをそろえる。
- **留意点**：S045は公式講演概要のみを確認。表の具体的な列構成、実装手順、効果測定までは確認していない。

#### T085 バンク・反復動画の再利用

- **確認文脈／日本との関係**：テレビアニメ／実践＋分析。
- **操作**：既存の背景、作画、映像や、歩行・揺れなどの反復する動画を再使用する。再利用する単位と前後のカットを調節し、現在の場面と意味が合うかを確認する。
- **狙い**：反復表現を制作資源として運用する。
- **留意点**：過去映像のバンクと短い周期の作画リピートを、再利用の一群としてまとめた。無制限な反復が効果的という意味ではない。

## 5. 横断的な考察

### 5.1 共通するのは「一つの型」ではなく、選択を明示する作業である

三幕、ビートシート、クエスト階層、伏線の接続、場面のゴールと決断は、同じものの別名ではない。全体の分割、出来事同士の関係、読者に与える情報、局所的な行動の連鎖という異なる問題を可視化する。それらを機械的に重ねるより、何を点検したいのかに応じて枠組みを選ぶのが、本カタログの想定する使い方である。日本語の紹介資料と国内の計算的提案は、接続可能性がある一方、理論の由来や検証方法が異なる。[S030](#s030)–[S034](#s034)、[S003](#s003)–[S005](#s005)、[S007](#s007)、[S075](#s075)。

例えば、人物が欲するものと必要とするものの区別を検討したうえで、どの場面がその食い違いを表し、どの行動でテーマに接続するかを考える、という読み方はできる。しかし「人物は必ず成長すべき」と結論してはいけない。アークの解説自体にフラット型とネガティブ型が含まれるからである。[S035](#s035)、[S078](#s078)。

### 5.2 表現の省略と情報不足は同じではない

止め絵、背景、画面外の音、小物、非描写は、何も伝えない状態とは限らない。例えば渡部の技法整理では、動く対象の選択、画面外へ行動を置く処理、背景、バンク等が歴史的な制作条件の中で論じられる。氷川の作品分析では、日常動作や空間・時間の連続性が翻案の効果に関係付けられる。本報告は、これらを単なる予算削減か、単なる装飾かという二択では扱わない。ただし、資料が論じる時代・作品を超えて「少ない作画のほうが優れる」と一般化する根拠もない。[S009](#s009), pp.26–28；[S010](#s010), pp.40–43。

音についても、同じ「画面外の声」や音画のずれが同一効果を生むわけではない。小津『東京暮色』に関する正清の論考は、一般的な反応ショットの親密さの説明と、当該作における声の圧力・憑依的な効果を区別している。音楽付加時点の実験は、映像が意図する感情によって結果が異なるとする。このような差を消して「音はこう使えばよい」という規則にしない。[S059](#s059), pp.38–42；[S060](#s060), p.58。

### 5.3 ゲームでは、情報の所在とプレイ履歴も構成要素になる

ノベルゲームの分岐は、選択肢の文章だけで成立するのではない。現在の状態を記録する変数、別のプレイにも残る記録、選択先と再合流点の指定などが、どの内容をいつ読めるかを決める。したがって、出来事の時系列に加え、**到達条件とプレイヤーの既読情報**を整理する必要があるというのが、本報告による操作上の含意である。[S052](#s052)–[S054](#s054)、[S015](#s015), pp.42–43。

一方、ロアサポートや人物名鑑は、プレイ履歴のフラグそのものとは異なる。物語の進行とは別に人物・世界の情報を参照する仕組みであり、本編への説明集中を避ける選択肢として整理した。ただしCEDEC2024の資料は公式概要だけなので、細かな操作仕様や理解度向上の測定値までは主張していない。[S047](#s047)、[S048](#s048)。

### 5.4 個人の発想法とチームの点検工程は分けて記録すべきである

頭の中で人物を増やす、台詞を先に書く、文字案からネームへ進むといった個人の方法と、シーン表、プリビズ、フラグ・遷移図の共有といった制作管理は、同じ創作行為の中でも目的と作業単位が異なる。[S087](#s087)、[S045](#s045)、[S051](#s051)。S051の図式化はチーム内の共有についての説明であり、プレイヤーに内部フラグを表示するUIの説明ではない。

また、初稿であらかじめ伏線を設計することと、全体完成後に前半へ前振りを足すことは両立しうるが、同じ工程ではない。後者についての二次報道を、未使用設定の再利用一般や、最初から完全な設計図が必要という主張に広げない。[S051](#s051)。

### 5.5 引用・分析・創作での使い分け

- **引用の入口として**：T番号から根拠資料・頁へ進み、原資料の該当箇所を確認する。原典の術語と本報告の編集見出しを区別する。
- **作品分析のコード候補として**：何を数え、どこを一単位とするかを別途定義する。「見つかった」ことから作者の意図を推定しない。複数分析者を用いるなら一致度の確認が必要である。
- **創作上の診断として**：「目的が曖昧」「説明が集中」「回収が唐突」「参照情報が不足」等の問題ごとに該当項目を選ぶ。116項目を全部採用するためのチェックリストにはしない。
- **比較研究として**：媒体・時代・出版環境を固定するか、その差を記録する。紹介記事が多い理論ほど実践者が多い、といった推定には使わない。

これらは本報告の利用提案であり、それ自体が効果を比較実験した結果ではない。

## 6. 限界と学術引用上の注意

### 6.1 包括性の限界

1. **探索的な収集であり、漏れゼロではない。** 広い操作範囲を確保したが、全出版物・全作品・全業界の悉皆調査ではない。116という数を技法の総数や創作理論の完成度とみなさない。
2. **年代の偏りがある。** 採用した日付既知の文書は2007〜2025年で、戦後初期・高度成長期・1980〜90年代の一次制作資料を年代別に体系収集したものではない。古い作品を後年の論文で論じることと、当時の制作意図を一次史料で確定することは別である。
3. **出版社・作家・作品の偏りがある。** 漫画の実務資料は集英社に、翻訳創作論の紹介はフィルムアート社に偏る。TVドラマの直接の制作証言は主として野木亜紀子の二記事である。一出版社・一作家の助言を媒体全体の合意と扱わない。ライトノベル各ジャンル、縦スクロール専用作品、配信ドラマ、インディーゲーム等の体系的な比較も不十分である。
4. **公開範囲への依存がある。** 書籍全体の頁付け、講義の非公開部分、会員限定の講演資料等は根拠にしていない。本文を確認できない候補は不採用とし、概要から確認できるものは概要に限定した。
5. **資料間の独立性は保証しない。** 複数の記事が同じ原著・理論を紹介していることがある。59文書は59個の独立した理論・実験・創作者を意味しない。
6. **記述から処方への変換がある。** 作品論の解釈を「〜する」という操作に変えた部分は、本報告の総合である。原著者が同じ手順を推奨したと逆に引用しない。
7. **書誌には確認できない値が残る。** 公開日・改訂日・査読状況等を推測で埋めていない。特定記事の更新日、メタデータ、刊行日、講演日、取材日を分けている。

### 6.2 日付・資料種別の重要な注意点

- **S007**：誌面は2017年3月14日、41巻12号。プラットフォームの2021年という値を刊行年に置き換えない。
- **S010**：誌面の刊行日と2021年のオンライン公開日を分ける。

- **S045・S046・S047・S049**：CEDECの公式講演概要。開催日をそのまま概要ページの公開日と呼ばない。発表資料・講演全体を読んだとも記載しない。
- **S051**：2025年8月4日は本文の **Updated** 表示。初回公開日は未確認であり、JSONLでも更新日とする。
- **S072・S073**：記事の初出・改訂日をHTMLメタデータから取得。本文中に同じ日付表示があると確認したわけではない。
- **S087**：記事公開日2020年7月2日と取材日2020年6月17日を分ける。元の改訂時刻メタデータも別に残し、刊行日に置き換えない。
- **フィルムアート社の記事群**：引用対象は日本語の紹介記事であり、紹介された原著・翻訳書の全文を読んだ引用ではない。記事の公開日が分からない場合、書籍の発売日を転用しない。

### 6.3 推奨する引用のしかた

**第一に、事実や理論を論証する際は、原資料を引用する。** 本報告のT番号は参照を容易にするが、DOIや誌名・著者・頁に代わる標準的な書誌識別子ではない。引用例の形は次のようになる。

> 渡部（2015:26–28）は、限られた作画枚数を前提にした処理として、動かす対象の限定、背景・画面外・バンク等を論じる。

この場合の出典は[S009](#s009)である。実際の投稿・提出先に合わせて、使用文献欄の著者・誌名・巻号・頁・DOIから指定書式を作り、原資料の該当頁を再確認する。本報告を「現代日本のアニメはすべて同じ枚数で作られる」という主張の出典にしてはならない。

**第二に、本報告の分類や操作化そのものを利用する際は、その編集性を明記する。** 例えば「本カタログT070の整理に従い、対象作品の線を注意配分の操作としてコード化した」のように書き、版1.0・作成日・項目ID・保存ファイル名を併記する。これを原典の著者が示した正式な分類名としない。

**第三に、二次資料から未読の一次資料を読んだように引用しない。** 出版社の紹介に含まれる原著者の言葉や、講演報道に含まれる発言を用いるなら、直接確認した資料が紹介記事・報道であることを示す。未読の本・スライドの頁を補ってはいけない。

**第四に、評価の軸を取り違えない。** 注意課題の成績、連続性判断、自由記述、自己報告、読者アンケート、売上、芸術的評価は同じ指標ではない。制作者の成功談や編集者の経験則は重要な実務資料だが、統制実験による普遍的効果の証明とは異なる。

## 8. データの利用方法

`sources.jsonl` は1行1文書、`techniques.jsonl` は1行1技法のUTF-8 JSON Linesである。`source_id` と `evidence[].source_id` を結合し、`technique_ids` で逆引きできる。S番号の欠番は選別履歴を保つために残した。

`screening_log.jsonl` は87件の候補URL記録と採否理由を収録する。S080・S081はそれぞれS015・S055の書誌証人として統合し、独立文献数に加えていない。`technique_index.csv` は表計算向けの索引、`manifest.json` は件数、`README.md` はスキーマと引用上の注意を示す。原資料のHTML・PDFや書籍本文は同梱していない。

```python
import json
from pathlib import Path
sources = {x["source_id"]: x for x in map(json.loads, Path("sources.jsonl").read_text(encoding="utf-8").splitlines())}
techniques = list(map(json.loads, Path("techniques.jsonl").read_text(encoding="utf-8").splitlines()))
item = next(t for t in techniques if t["technique_id"] == "T070")
for evidence in item["evidence"]:
    print(sources[evidence["source_id"]]["title"], evidence["pinpoint"])
```
