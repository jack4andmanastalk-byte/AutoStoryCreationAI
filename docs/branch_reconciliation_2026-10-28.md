## 検証と制限

- `test_untrusted_index_never_hides_project_corruption` は main 側で成功し、対象ブランチを
  別ディレクトリに展開して同テストを実行すると、欠落成果物と改変 world を見落とし
  `ok=True` となって失敗した。これは**不完全な index を手動で置いた条件**での再現であり、
  通常操作による発生頻度を意味しない。
- source-work の確認は、対象ブランチの `build_plan` と固定台本に架空の作品名を渡し、
  `brief.md` には含まれるが provider の plan prompt には含まれないことを確認した。
- PDF の非空テキスト抽出は完全・正確な復元を保証しない。削除後のエラーや中断が全体的に
  原子的にロールバックされる保証もない。削除対象は実行前にバックアップし、再利用の権利を
  確認する。外部の大規模データや著作権存続作品は本変更で追加しない。
- この作業は対象ブランチの不具合を直接修正したわけではない。後続の機能移植や再設計を
  行う場合は現行 main 上で独立した変更とテストに分ける。
