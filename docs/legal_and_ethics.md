# 権利・倫理に関するメモ

本リポジトリは研究目的の公開データセットの整備です。取得・再配布・利用の判断は
必ず下列の一次情報に基づいて行ってください。

## 1. 青空文庫

* 公式サイト: <https://www.aozora.gr.jp/>
* 収録ファイルの取り扱い規準: <https://www.aozora.gr.jp/guide/kijyunn.html>
* 作品ごとの著作権フラグは CSV の `作品著作権フラグ` 列に「あり」「なし」で記録されています。

基本方針:

1. **著作権存続作品（フラグ「あり」）は再配布しません。** 本文のダウンロード・PDF 化を行いません。
2. フラグ「なし」の作品についてのみ、規準に従い attribion（出典 URL・作者名・作品名）を
   伴って利用します。本リポジトリの JSONL は `url` / `authors` / `license` にこれらを持ち、
   PDF の表紙にも出典を出力しています。
3. 二次利用（二次創作・学習・再配布）を行う場合は、規準の「二次利用」の条項を確認してください。

## 2. 小説家になろう

* 公式サイト: <https://syosetu.com/>
* 開発者向け API の利用ガイドライン: <https://dev.syosetu.com/site/guideline/>
* 小説 API の仕様: <https://dev.syosetu.com/man/api/>

基本方針:

1. **API の利用は非商用・教育・研究用途に限定**されます。ガイドライン记载の Allowed Purpose
   を確認してください。
2. **作品の著作権は作者に帰属**します。GPL などの公開ライセンスは付与されていないため、
   取得した本文を「作者の許可なく再配布」することはできません。
3. 本リポジトリでは、**公式サイトが無料公開している WEB 版のテキストのみ**を扱う設計に
   しています。商業化作品（紙書籍・電子書籍・ゲーム化など）の印刷版・電子書籍版は
   取得も再配布も行いません。購入先は公式ストアの URL を `rights` / `extra` に記録します。
4. R15 要素を含む作品は、研究用データセットでは既定で除外しています
   （`narou.include_r15` で変更可能）。未成年が関する可能性のあるため、扱う場合は
   利用上の注意と責任の所在を明示してください。

## 3. 商用化作品について（利用者が最も注意すべき点）

「小説家になろうで商業化された作品」の PDF を無取得で入手することはできません。

* 商業化は出版社と著作者との契約に基づき行われます（例: KADOKAWA、Amazon Kindle）。
* 一般的に、**公式サイトで無料公開されている WEB 版** と **商業版** は内容が異なります。
  商業版には修正・追加のエピソードが含まれる 경우가中心和です。
* 無断で商業版の PDF を収集・再配布すると、著作権侵害 となる可能性があります。
* 本パイプラインは、合法的に取得できる WEB 版のみを扱う設計です。商業版が必要な場合は
  正規経路（書店・電子書店）で購入してください。

## 4. 引用と出典表示

論文・ブログ・社内資料で本データセットを用いる場合は、次を明記してください。

```
青空文庫（https://www.aozora.gr.jp/ , 取得日: YYYY-MM-DD）
小説家になろう（https://syosetu.com/ , 取得日: YYYY-MM-DD）
```

各レコードには `url` / `published_at` / `text_path` があるため、記録単位での追跡が可能です。

## 5. 機械可読な権利情報

`rights` フィールドは機械可読な形で以下を保持します。

| フィールド | 意味 |
| --- | --- |
| `source` | 取得元（`Aozora Bunko` / `Syosetsuka ni Narou`） |
| `copyright_flag` | 青空文庫の作品著作権フラグ（`true` = 再配布不可） |
| `commercialized` | 小説家になろうの商業化判定（`null` = 未判定） |
| `note` | 人間向けの注記 |
