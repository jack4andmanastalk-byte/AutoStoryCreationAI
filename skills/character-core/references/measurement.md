# 測定仕様 — 検査項目と、判定しないこと

## 検査項目（6 検査。すべて機械的）

| 検査 | 合格条件 | 重要度 |
| --- | --- | --- |
| `core_declared` | WANT・NEED・恐れ・行動原理があり、WANT と NEED が別文 | medium |
| `views_separated` | 自己像と 1 件以上の他者像がある | medium |
| `choices_predicted` | 状況と選択の組が 3 件以上ある | medium |
| `voice_fixed` | 30 字以上の口調サンプルと 1 件以上の語彙規則がある | medium |
| `arc_decided` | 終点・変わる選択・変わらない選択がある | medium |
| `canon_grounded` | 人物 ID が canon に存在する（canon があれば） | medium（canon 無しは skipped） |

重要度に high はない。人物設計の欠陥は「矛盾」ではなく「説明の弱さ」である。

## 判定しないこと（非目標）

| 問い | なぜ判定しないか | 代わりに |
| --- | --- | --- |
| 人物が魅力的か | 機械的に測れない | L2/L3 |
| 行動から性格が読めるか | 本文の判定 | L2 の `character_consistency` |
| 性格変化が都合よくないか | 本文の判定 | L2＋人間の読解 |
| 口調が一貫しているか（本文） | 本文の判定 | `voice-style`＋L2 |
| 脇役が引き立て役に堕していないか | 構造だけでは測れない | 全員に核を書く運用＋L2 |

## 予測の書き方

良い予測は「核から説明できるが、意外性がある」。悪い予測の例：

* 「敵が来たら戦う」——状況も選択も一般的すぎる。
* 「ピンチになったら頑張る」——核（WANT/NEED）との接続がない。
* 3 件が同じ状況の言い換え——状況を変える（時間・相手・代償を変える）。
