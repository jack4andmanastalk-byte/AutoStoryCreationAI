# `characters.yaml` の書式

canon の `characters`（状態の記録）とは別物。こちらは選択のモデル（設計書）。
ID で対応させる。

```yaml
characters:
  - id: aria                # canon の人物 ID と一致させる
    want: 灯りを絶やさないこと
    need: 自分の選択で灯りを守ること
    fear: 灯りを絶やし、船を見殺しにすること
    wound: 幼い頃の嵐の夜の責任追及
    secret: 鍵の貸し手を父に言っていない
    principle: 確かめずに信じない。信じたものは守る
    self_view: 父の言いつけを守る堅実な娘
    others_view:            # 1 件以上。「誰から見れば」を添える
      - 父から見れば心配性の娘
    predictions:            # 3 件以上。状況と選択の組
      - situation: 鍵の返却と灯りの番が重なったら
        choice: 灯りの番を優先し、鍵は後で追う
    speech:
      sample: 「灯りは消さない」とアリアは言い、革袋を握りしめた。  # 30 字以上
      vocab: [灯り, 鍵, 帳面]   # 使う語。1 件以上
      avoid: [～かしら]         # 避ける語。任意
    arc:
      endpoint: 言いつけを守る娘から自分の選択で守る灯台守になる
      changed: [父の命令への従い方]
      unchanged: [灯りを絶やさないこと]
    bans:                   # らしくない言動。任意
      - 確かめずに他人の言い分を信じる
notes: 任意のメモ
```

## 欄の意味

| 欄 | 役割 |
| --- | --- |
| `want` / `need` | 失いたくないものと、本当に必要なもの。同一文は不可 |
| `fear` / `wound` / `secret` | 選択を歪める圧力。空欄可だが書くことが望ましい |
| `principle` | 行動原理。予測の判定基準になる |
| `self_view` / `others_view` | 自己像と他者像。ずれが人物の厚みになる |
| `predictions` | 圧力下の選択の予測。3 件以上 |
| `speech` | 口調の固定。サンプル＋語彙＋回避 |
| `arc` | 終点・変わるもの・変わらないもの |
| `bans` | らしくない言動。L2 の `character_consistency` への入力になる |

## canon との分担

| 設計書（このスキル） | canon（`continuity-ledger`） |
| --- | --- |
| なぜそう選ぶか（核・原理・アーク） | いまどういう状態か（生死・所在・既知） |
| どう話すか（口調の固定） | 何を知っているか（事実 ID） |
| 何をしないか（禁止行動） | いつ変わったか（マーカー） |
