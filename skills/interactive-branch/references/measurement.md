# 測定仕様 — 検査項目と、判定しないこと

## 検査項目（7 検査。すべて機械的）

| 検査 | 合格条件 | 重要度 |
| --- | --- | --- |
| `graph_grounded` | 開始点・辺の端点・via が実在し、種別が 3 値のいずれか | medium |
| `paths_reachable` | 全節点に開始点から到達でき、全節点から結末に到達できる | medium |
| `endings_terminated` | 結末から辺が出ず、結末に内容があり、結末以外の行き止まりがない | medium |
| `flags_declared` | 条件・更新・初期の旗が宣言され、意味がある | medium |
| `conditions_sound` | 必須の旗がどこかで設定され、全辺がどれかの状態で辿れる | medium（上限超過の省略は low） |
| `options_meaningful` | 選択肢が 2 件以上、表示が重複せず、全選択肢に辺がある | medium |
| `merges_noted` | 2 方向以上の合流点に覚え書きがある | medium |

## 条件の検査（`conditions_sound`）

（節点，旗集合）の積空間を幅優先探索し、辿れない辺を見つける。
上限（20,000 状態）を超えたら検査を省略し、low で報告する。
推測で pass/fail を出さない。

## 判定しないこと（非目標）

| 問い | なぜ判定しないか | 代わりに |
| --- | --- | --- |
| 選択が面白いか | 機械的に測れない | L2/L3 |
| 選択に意味があるか | 意味の判定 | L2/L3（構造は本スキル） |
| 分岐の価値とコストの釣り合い | 制作判断 | P18 を参照し、人間が判断 |
| 台詞・イベントの選択の妥当性 | 本文中の運用 | P20 を参照し、L2 に回す |
| 経路ごとの知識状態 | 別スキル | `relationship-web` の知識表 |
