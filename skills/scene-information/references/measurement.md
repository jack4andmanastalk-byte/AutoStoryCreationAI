# 測定仕様 — 検査項目と、判定しないこと

## 検査項目（6 検査。すべて機械的）

| 検査 | 合格条件 | 重要度 |
| --- | --- | --- |
| `scene_purposed` | 目的・対立・変化がある | medium |
| `tension_designed` | 緊張の型が 6 語彙のいずれか | medium |
| `knowledge_tracked` | 人物・事実が実在し、得た事実が開示計画にある | medium |
| `disclosure_planned` | 開示と保留が分かれ、保留に理由があり、事実が実在 | medium |
| `foreshadow_tagged` | 回収が実在の布石を指し、仕掛けは新規 ID で回収より前 | medium |
| `scenes_cover` | 全章に場面があり、場面の章が実在（canon があれば） | medium（canon 無しは skipped） |

## 判定しないこと（非目標）

| 問い | なぜ判定しないか | 代わりに |
| --- | --- | --- |
| 場面が面白いか | 機械的に測れない | L2/L3 |
| 緊張の型の使い方が正しいか | 本文中の運用の判定 | L2 |
| 驚きに根拠があるか（意味） | 意味の判定 | 伏線の配置＋L2 |
| 伏線が本文で回収されているか | 本文の監査 | `continuity-ledger` |
| 省略が効いているか | 本文の判定 | L2 |
