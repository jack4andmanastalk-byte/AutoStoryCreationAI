# 測定仕様 — 検査項目と、判定しないこと

## 検査項目（5 検査。すべて機械的）

| 検査 | 合格条件 | 重要度 |
| --- | --- | --- |
| `acts_cover` | 幕が章を過不足なく覆い、各幕に問いがある | medium |
| `turns_placed` | 転換点が 3～5 件あり、各転換点に選択と実在する章がある | medium |
| `subplots_allocated` | 副筋に節目と本筋への合流がある | medium |
| `ending_designed` | 結末の型・要約・余韻がある | medium |
| `debts_listed` | 未回収が実在の布石に結び付くか、意図的と宣言される | medium |

## 判定しないこと（非目標）

| 問い | なぜ判定しないか | 代わりに |
| --- | --- | --- |
| 筋が面白いか | 機械的に測れない | L2/L3 |
| 転換点が本当に選択か | 意味の判定 | 書き手の自己点検＋L2 |
| 型の選択が妥当か | 規範の押し付けになる | 比較表を渡し、選ばせる（本スキルは検証する） |
| 伏線が本文で回収されているか | 本文の監査 | `continuity-ledger` |
| 場面が機能しているか | 場面単位の設計 | `scene-information` |
