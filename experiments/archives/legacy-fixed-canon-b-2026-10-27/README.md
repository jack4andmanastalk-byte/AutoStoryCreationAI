# 旧 Batch B（固定 canon）差分の保全

このディレクトリは旧 `arena/f3ec8a91-autostorycreationai` の**履歴資料**であり、
現行の同名実験を変更したり、旧実験を再開・完了扱いにしたりするものではない。

- 旧先端: `fab7e5cf5c7039e7ed31365d5b20874acc1c8615`
- 親: `b2701a87e035a65c23ea254318b48bd3a93dbc98`（main の履歴に存在）
- `source-change.patch`: 上記の親から旧先端までの **21 ファイル全差分**（コンテキスト 0 行）。SHA-256:
  `e966b42b4f39a3c1e87fc8500b0228701b20f6bd5144c245fe2a03915f8127d4`。
- 旧 `preregistration.json` SHA-256:
  `ecaccfe468b7ca926ff5fe5171d07f3a6ffb87348961b796dc67482f97701b2f`。
- 当時の条件は Batch A と同じ canon を固定し、**plan は実行せず design → draft** を
  1 標本計画。計測は `not_run`、relay の要求 `CF27` は回答待ち。完走した結果ではない。
- main の `experiments/2026-10-realrun-b-t01/` は plan を実行する**別条件の登録・完走済み
  実験**であり、旧登録で上書きしない。完走済み結果から旧条件の結論を導かない。

patch には事前登録、固定 canon、要求、`not_run` の結果、当時の計測器・テストと、
当時の README・説明・コード変更が含まれる。架空の `t01` 研究タスクの記録であり、
小説家になろうの本文は含めない。スナップショットには応答の証拠はなく、
現在のプロンプトや計測器と互換・再現可能であることを保証しない。秘密情報の単純な形式
チェックは完全な権利・プライバシー審査ではない。

## 確認したこと

親コミットを一時ディレクトリに `git archive` で展開し、patch を `git apply --check --unidiff-zero`、
適用後の全 21 ファイルを旧先端の Git blob とバイト比較した。登録の SHA-256 も一致。
これは差分保全の検証であり、実験の実施・再開や生成品質を確認したものではない。
`tests/test_legacy_branch_archive.py` は patch のハッシュ、登録と回答待ち状態を固定する。

## 復元して調査する場合

**現行 checkout に直接適用しない。** 同じパスに異なる事前登録・実験結果が存在する。
リポジトリの Git 履歴から上記の親コミットを空の別ディレクトリへ `git archive` で展開し、
そこだけに `git apply --unidiff-zero` で patch を適用する。コンテキスト 0 行のため、指定の親以外に適用しない。復元先を明示して確認し、実行や再登録が必要なときは、
既存の実験記録と条件を変えない別の計画とする。公開・非公開データの扱いは
[設計・注意書き](../../../docs/private_research_design.md) に従い別途確認する。
