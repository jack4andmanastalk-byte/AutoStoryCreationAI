# バッチ A: Stage B の入力プロンプト（3 章ぶん・全標本で共通）

これは `scripts/export_stageb_prompts.py` が、パイプラインと同じ関数
（`run_twostage.stage_b_rewrite_prompt`）で出力した**そのままのプロンプト**です。
修正しないでください（1 文字でも変えると回答が stale として拒否されます）。

## 使い方（別チャットで答える場合）

1. `sample-1` は **ch01 → ch02 → ch03 の順**に、下のプロンプトをそのまま貼って本文を書いてもらう。
2. `sample-2` と `sample-3` も**同じプロンプト**です。3 標本の違いは**回答（本文）だけ**で、
   それぞれ別の機会に、前の標本の回答を見せずに書いてください（見せると独立標本になりません）。
3. 返ってきた本文を、対応するキーのファイルに JSON で置きます（下の「回答の置き場所」）。
4. 章が検査に落ちると**修復プロンプト**が新しく出ます。それは回答を見た後に決まるので、
   そのとき `PROMPTS.md`（run ディレクトリ）または `chat_operator.py --status` で取り出してください。

## 回答の置き場所（`--seed 0` で 3 標本とも同じキー）

```
experiments/2026-10-realrun-a-t01/relay/sample-1/responses/two-stage-t01-s1-stage_b-ch01-a1.json
experiments/2026-10-realrun-a-t01/relay/sample-1/responses/two-stage-t01-s2-stage_b-ch02-a1.json
experiments/2026-10-realrun-a-t01/relay/sample-1/responses/two-stage-t01-s3-stage_b-ch03-a1.json
```

`sample-2` / `sample-3` は `relay/sample-2` / `relay/sample-3` の下に同じ名前で置きます。

```json
{
  "text": "<本文（マーカー {{time: day=1}}{{location: 灯台}} を含めてよい）>",
  "model": "arena-agent-mode",
  "model_version": "unversioned-2026-10-26",
  "provenance": {"origin": "fresh"}
}
```

`origin` は、このバッチのために新しく書いたなら `fresh`。過去の走りの本文を流用したなら
`{"origin": "reused", "source_run_id": "..."}` と正直に書いてください（その標本は標本として扱いません）。
