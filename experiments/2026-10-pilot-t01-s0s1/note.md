## この記録の位置づけ

**「AI がうまく書けた」という記録ではありません。**このリポジトリは鍵を持たないため、
これまで生成は台本（`scripted`）でしか通っていませんでした。この pilot は、
**プロトコルの尺（3 章・合計 3,000〜4,200 字）で、実テキストが S0/S1 の最後まで通るか**

担い手は対話セッションのオペレータで、**モデル名も版も固定できません**。
したがって §5 の **G5（同一 seed・同一設定で出力が一致するか）は未達**であり、
§5 の規定により、下の L1 の値は**参考値**です。G3（選好）・G4（識別）は測っていません。

品質（L2/L3）の比較は仮説に入れていません。1 人のオペレータが両系を書いている時点で、

## 限界

- **G5 未達**。担い手のモデル版を固定できず、同じプロンプトでも同じ文は出ない。
  第三者による再実行ができないので、上の値は参考値である（§5）。
- **L1 のみ**。L2（6 次元）も L3（選好・識別）も測っていない。品質の主張はできない。
- **違反 0 は「監査を通過しやすい書き方をした」以上の意味を持たない**。オペレータは
  マーカー記法と検査項目（`src/asc/story/continuity.py`）を読んだうえで書いている。
  モデルが同じ 0 を出すとは限らない。この pilot は「検査が動く」ことの確認であって、
  「検査に落ちない生成」の証明ではない。
- **seed は独立試行ではない**。同じプロンプトに対してオペレータが書き分けただけで、
  分布からの抽出ではない。したがって区間（CI）は、この 3 稿のばらつきしか表さない。
- **S0 と S1 を同じ担い手が書いている**。盲検もランダム化もしていないため、
  系の差と書き手の癖が分離できない。S1 のほうが整っているのは、canon の効果と、
  オペレータが S1 の制約を意識して書いたことの両方で説明できる。
- **N=3・単一タスク**。t01 は幻想 1 題で、他ジャンル（現代・歴史）は試していない。
- **本文はコミットしていない**（`experiments/README.md` の規約）。`runs/` と
  `build/operator/pilot-t01/` は git 管理外なので、この記録だけでは本文を検証できない。
