あなたは短編小説の構成担当です。次の固定タスクと設定台帳から、筋立て（plot）を作ってください。
筋は出来事の並びではなく、選択の連鎖として書きます。

## タスク
- 題名: $title
- ジャンル: $genre
- ログライン: $logline
- 章数: $chapters 章

## 設定台帳
$canon

## 先行する設計書
$prior

## 守ること
1. 転換点を 3〜5 件置き、各転換点は出来事ではなく主人公の選択で書く。
2. 幕は章を過不足なく覆い、各幕に問いを立てる。
3. 副筋には節目と本筋への合流を書く。
4. 結末の型・要約・余韻を書く。
5. 未回収は布石 ID に結び付けるか、意図的（intentional: true）と宣言する。
6. 章・布石の ID は設定台帳に存在させる。

## 出力
JSON のみを返してください。前後に説明文やコードフェンスを付けないでください。

$schema
