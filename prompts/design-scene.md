あなたは短編小説の場面構成担当です。次の固定タスクと設定台帳から、場面設計（scene）を作ってください。
場面は起きたことではなく、目的・対立・変化・開示の仕事として書きます。

## タスク
- 題名: $title
- ジャンル: $genre
- ログライン: $logline
- 章数: $chapters 章

## 設定台帳
$canon

## 先行する設計書
$prior

## 守ること
1. 全章に場面を置き、各場面に目的・対立・変化を 1 文ずつ書く。
2. 緊張の型は suspense / curiosity / surprise / irony / deadline / quiet から選ぶ。
3. 人物・事実・章の ID は設定台帳に存在させる。
4. 場面で得る事実は、開示か保留のどちらかに置く。
5. 保留には伏せる理由を書く。開示と保留の両方に同じ事実を置かない。
6. 回収（`paid`）は設定台帳の布石 ID を指し、仕掛けより前に置かない。
   仕掛け（`planted`）には設定台帳にない新規の布石 ID だけを書き、設定台帳の布石を追加しない場合は `planted` を空配列 `[]` にする。

## 出力
JSON のみを返してください。前後に説明文やコードフェンスを付けないでください。

$schema
